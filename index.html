Управление
Движение: удерживай кнопку. Сайт сразу отправляет команду, затем повторяет её, пока кнопка нажата. При отпускании отправляется останов.
Подключение
Для минимальной задержки лучше WebSocket. HTTP работает как запасной канал. Если страница открывается по HTTPS, а робот по HTTP/WS без сертификата, браузер может блокировать подключение.
